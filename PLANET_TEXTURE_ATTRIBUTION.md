# Planet Texture Attribution

This project uses optional image-based planet maps from Solar System Scope when an internet connection and texture host are available. The maps are distributed under **Creative Commons Attribution 4.0 International (CC BY 4.0)**. The source notes that its maps are based on NASA imagery/elevation data, along with spacecraft and observatory imagery.

- Texture page: https://phet.solarsystemscope.com/textures/
- License: https://creativecommons.org/licenses/by/4.0/
- NASA/JPL planetary map archive: https://space.jpl.nasa.gov/tmaps/

The application keeps its procedural textures as an offline/error fallback. The visual maps are not a live satellite feed, and gas-giant cloud maps are illustrative snapshots rather than live atmospheric data.
