# Planet texture attribution

The app prefers online equirectangular planet maps from Solar System Scope:
https://www.solarsystemscope.com/textures/download/

Files used: 2k_mercury.jpg, 2k_venus_surface.jpg, 2k_earth_daymap.jpg,
2k_earth_clouds.jpg, 2k_moon.jpg, 2k_mars.jpg, 2k_jupiter.jpg,
2k_saturn.jpg, 2k_uranus.jpg, 2k_neptune.jpg.

License: Creative Commons Attribution 4.0 International (CC BY 4.0).
Attribution: Solar System Scope. The maps are visual planetary maps based on
spacecraft/observatory imagery and NASA elevation data; they are not all raw
NASA photographs and should not be described as direct satellite photographs.

Offline fallback: existing procedural textures remain available if the map host
cannot be reached. Internet access is needed to download image maps on first use.
